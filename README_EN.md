# Star Nebula Knowledge

**记录回忆，知识和畅想的地方**

个人知识库，基于 [VitePress](https://vitepress.dev) 构建，使用 [Obsidian](https://obsidian.md) 管理笔记。

## 特点

- 🌈 多样的主题和内容
- 📃 皆为 Markdown
- 🚀 由 [VitePress](https://vitepress.dev) 驱动
- 🗃 由 [Obsidian](https://obsidian.md) 驱动

## 如何使用

### 安装依赖

```shell
pnpm install
```

### 运行开发服务器

```shell
pnpm docs:dev
```

### 构建静态页面

```shell
pnpm docs:build
```
