知识库插件列表 ​

本文档由 vault/.obsidian/plugins 的实际安装情况整理（更新于 2026-07-17）。 当前 plugins/ 下共 15 个插件目录，其中 13 个已在 community-plugins.json 中启用，2 个未启用（含 1 个安装不完整）。

⚠️ 与旧版差异：旧文档中列出的 Admonition、Asciinema Player、Obsidian Footnotes Plugin、Obsidian Git、Auto Pair Chinese Symbol、File Explorer Note Count、Remember Cursor Position、Advanced Tables 当前并未安装在知识库中，已从本清单移除。如仍需这些插件，请手动在 Obsidian 社区插件市场安装。

必选 ​

⚠️ 以下插件参与了 vault 内容的创建、渲染或核心工作流。在 Obsidian 中打开本知识库时若不安装，已存在的画图、块引用、模板、查询等内容可能无法正常查看或编辑。

Dataview ​

  • 说明：面向"数据控"的复杂数据视图，支持用类 SQL 语法查询 Markdown 文件的元数据并可视化结果（本库"已发布的所有页面"等笔记依赖其查询）。
  • 类型：数据查询 / Markdown 语法拓展
  • 版本：0.5.68
  • 作者：Michael Brenan
  • 启用：是
  • 地址：Obsidian 社区插件市场

Excalidraw ​

  • 说明：手绘草图 / 白板工具，用于编辑和查看 Excalidraw 绘图，进入 4D 可视 PKM 世界。本库含约 70 个 .excalidraw 文件，缺它则无法查看这些手绘内容。
  • 类型：画图 / 可视化 PKM
  • 版本：2.23.8
  • 作者：Zsolt Viczian
  • 启用：是
  • 地址：Obsidian 社区插件市场

Diagrams（drawio-obsidian） ​

  • 说明：在笔记内或独立文件中绘制 Draw.io 图表（生成 SVG，也支持 .drawio）。本库含约 14 个 .drawio 文件，缺它则图表无法渲染。
  • 类型：画图 / 图表 / 文件解析
  • 版本：1.5.4
  • 作者：Sam Greenhalgh
  • 启用：是
  • 地址：Obsidian 社区插件市场

Copy Block Link ​

  • 说明：通过右键菜单复制块（block）和标题的链接。本库存在约 1769 处块引用（^id），缺它则难以跳转与维护这些引用。
  • 类型：Markdown 语法增强 / 块引用
  • 版本：1.0.4
  • 作者：mgmeyers
  • 启用：是
  • 地址：Obsidian 社区插件市场 · GitHub

Custom Attachment Location ​

  • 说明：用变量（${noteFileName}、${date:format} 等）自定义附件的存放位置（类似 Typora）。用于统一本库附件路径规范。
  • 类型：功能拓展 / 附件管理
  • 版本：10.3.4
  • 作者：mnaoumov（最初由 RainCat1998 创建）
  • 启用：否（已安装但未启用，建议启用以统一附件管理）
  • 地址：Obsidian 社区插件市场

Local Images Plus ​

  • 说明：扫描笔记中的外链媒体，下载并保存到本地，同时把链接改写为本地路径。用于把外链图片本地化，保证离线可用。
  • 类型：功能拓展 / 媒体管理
  • 版本：0.16.4
  • 作者：catalysm, aleksey-rezvov, Sergei Korneev
  • 启用：否（已安装但未启用，建议启用以完成图片本地化）
  • 地址：Obsidian 社区插件市场 · GitHub

Templater ​

  • 说明：高级模板引擎，支持 <% %> 脚本语法。本库有 3 个文件使用了 Templater 语法，缺它则模板无法渲染 / 执行。
  • 类型：模板 / 功能拓展
  • 版本：2.23.1（已于 2026-07-17 修复：补全缺失的 manifest.json 与 styles.css、覆盖对齐 main.js，并重新加入启用列表）
  • 作者：SilentVoid
  • 启用：是
  • 地址：Obsidian 社区插件市场 · GitHub
