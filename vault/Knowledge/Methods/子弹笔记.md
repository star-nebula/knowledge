# 子弹笔记

## 一句话概述

子弹笔记（Bullet Journal）是用符号系统快速记录、组织和追踪信息的方法论，核心原则是**结论第一**——重点/目标放最前面，再展开细节。

## 核心符号系统

| 符号 | 含义 | 说明 |
|------|------|------|
| `·` | 任务 | 待办事项 |
| `×` | 已完成 | 任务完成后将 `·` 改为 `×` |
| `>` | 迁移 | 推迟到后续处理 |
| `<` | 计划中 | 已排入日程 |
| `○` | 事件 | 发生的事，不是任务 |
| `-` | 笔记 | 事实、想法、观察 |
| `*` | 优先级 | 重要事项 |
| `!` | 灵感 | 值得扩展的想法 |

## 四大核心集子

1. **索引（Index）**：目录页，标注每个集子的页码
2. **未来记录（Future Log）**：年度概览，记录未来月份的事项
3. **月度记录（Monthly Log）**：当月日历 + 任务清单
4. **每日记录（Daily Log）**：当天的事项，快速记录

## 结论第一原则

> 笔记、汇报、记录——把**重点、目的、目标**放最前面，之后再写步骤或原因。

前提是你知道这件事的来龙去脉。这不是省略思考，而是让读者/未来的自己能快速定位核心信息。

## 适用场景

- 快节奏的技术工作中管理待办和信息流
- 会议纪要：结论前置，细节后置
- 学习笔记：先概括核心，再展开论证
