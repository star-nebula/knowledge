# 分发优先原则

好产品没人看，等于没有。对消费级产品而言，**分发（让对的人看到）和产品本身同等重要，甚至应更早布局**。

要点：

- 创始人若有过营销或代理背景，更应第一天就把获客当核心，而不是产品做完再想怎么卖。
- 早期用免费自然流量（Instagram / TikTok / Reddit）触达已经在讨论相关话题的人群，验证需求与共鸣。
- 有了牵引力后，再叠加达人合作、UGC 计划、付费广告来放大。

反面：只打磨产品、忽略分发，再好也容易沉没。
