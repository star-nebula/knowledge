逻辑与推理是人工智能的核心问题。符号主义人工智能脱胎于逻辑推理，所有概念通过符号及其关系表示，对符号进行逻辑推理以实现对知识的辨析。本章从命题逻辑、谓词逻辑、知识图谱推理和因果推理四个方面展开。

## 命题逻辑
命题逻辑是数理逻辑的基础，应用形式化规则对以符号表示的命题进行推理。

### 基本概念

| 概念         | 定义                                           |
| :----------- | :--------------------------------------------- |
| **命题**     | 一个能确定为真或为假的陈述句。                 |
| **原子命题** | 不包含其他命题作为组成部分的命题（简单命题）。 |
| **复合命题** | 通过命题联结词组合原子命题得到的新命题。       |

### 命题联结词

| 联结词   | 符号                  | 含义                         | 真值表（$p, q: F/T$）             |
| :------- | :-------------------- | :--------------------------- | :-------------------------------- |
| 与       | $p \land q$           | 合取，“$p$ 且 $q$”           | F, F, F, T                        |
| 或       | $p \lor q$            | 析取，“$p$ 或 $q$”           | F, T, T, T                        |
| 非       | $\neg p$              | 否定，“非 $p$”               | T, T, F, F（对应 $p$ 的真值取反） |
| 条件     | $p \rightarrow q$     | 蕴含，“如果 $p$，则 $q$”     | T, T, F, T                        |
| 双向条件 | $p \leftrightarrow q$ | 双向蕴含，“$p$ 当且仅当 $q$” | T, F, F, T                        |

> **重要**：$p \rightarrow q$ 为假**仅当** $p$ 真而 $q$ 假；当 $p$ 为假时，$p \rightarrow q$ 恒为真（空集是任何集合的子集）。

### 常用逻辑等价式

| 等价式                                                       | 说明     |
| :----------------------------------------------------------- | :------- |
| $\alpha \rightarrow \beta \equiv \neg \alpha \lor \beta$     | 蕴涵消除 |
| $\neg (\alpha \land \beta) \equiv \neg \alpha \lor \neg \beta$ | 德摩根律 |
| $\neg (\alpha \lor \beta) \equiv \neg \alpha \land \neg \beta$ | 德摩根律 |
| $\alpha \rightarrow \beta \equiv \neg \beta \rightarrow \neg \alpha$ | 逆否命题 |
| $\neg \neg \alpha \equiv \alpha$                             | 双重否定 |
| $(\alpha \land \beta) \lor \gamma \equiv (\alpha \lor \gamma) \land (\beta \lor \gamma)$ | 分配律   |

### 推理规则

| 规则         | 形式                                                         |
| :----------- | :----------------------------------------------------------- |
| 假言推理     | $\alpha \rightarrow \beta, \alpha \Rightarrow \beta$         |
| 与消解       | $\alpha_1 \land \alpha_2 \land \dots \land \alpha_n \Rightarrow \alpha_i$ |
| 与导入       | $\alpha_1, \alpha_2, \dots, \alpha_n \Rightarrow \alpha_1 \land \alpha_2 \land \dots \land \alpha_n$ |
| 双重否定消去 | $\neg \neg \alpha \Rightarrow \alpha$                        |
| 单项归结     | $\alpha \lor \beta, \neg \beta \Rightarrow \alpha$           |
| 归结         | $\alpha \lor \beta, \neg \beta \lor \gamma \Rightarrow \alpha \lor \gamma$ |

### 范式

- **析取范式 (DNF)**：有限个简单合取式的析取，如 $(\neg \alpha_1 \land \alpha_2) \lor \alpha_3$。
- **合取范式 (CNF)**：有限个简单析取式的合取，如 $(\alpha_1 \lor \alpha_2) \land \neg \alpha_3$。
- 任意命题公式都存在与之等值的 DNF 和 CNF（不唯一）。

## 谓词逻辑
命题逻辑无法表达“局部与整体”“一般与个别”的关系（如苏格拉底三段论），因此引入谓词逻辑，将原子命题细分为个体、谓词和量词。

### 基本元素

| 元素                   | 定义                                                         | 示例                                     |
| :--------------------- | :----------------------------------------------------------- | :--------------------------------------- |
| **个体**               | 研究对象中独立存在的具体或抽象概念，可为常量（如苏格拉底）或变量（$x, y$） | 苏格拉底, $x$                            |
| **谓词**               | 刻画个体属性或个体间关系的元素，值为真/假                    | $\text{Person}(x)$, $\text{Father}(x,y)$ |
| **全称量词** $\forall$ | 表示“所有的”“每一个”                                         | $(\forall x)P(x)$                        |
| **存在量词** $\exists$ | 表示“存在”“某些”                                             | $(\exists x)P(x)$                        |

### 量词等价关系

| 关系                                               | 说明                                               |
| :------------------------------------------------- | :------------------------------------------------- |
| $(\forall x)P(x) \equiv \neg (\exists x)\neg P(x)$ | 所有 $x$ 满足 $P$ 等价于 不存在 $x$ 不满足 $P$     |
| $(\exists x)P(x) \equiv \neg (\forall x)\neg P(x)$ | 存在 $x$ 满足 $P$ 等价于 并非所有 $x$ 都不满足 $P$ |
| $\neg (\forall x)P(x) \equiv (\exists x)\neg P(x)$ | 并非所有 $x$ 满足 $P$ 等价于 存在 $x$ 不满足 $P$   |

### 推理规则

| 规则              | 符号                               | 含义                                 |
| :---------------- | :--------------------------------- | :----------------------------------- |
| 全称量词消去 (UI) | $(\forall x)A(x) \Rightarrow A(y)$ | 对所有 $x$ 成立，则对任意 $y$ 成立   |
| 全称量词引入 (UG) | $A(y) \Rightarrow (\forall x)A(x)$ | 若对任意 $y$ 成立，则对所有 $x$ 成立 |
| 存在量词消去 (EI) | $(\exists x)A(x) \Rightarrow A(a)$ | 存在某个 $x$，可指定一个常量 $a$     |
| 存在量词引入 (EG) | $A(a) \Rightarrow (\exists x)A(x)$ | 若某个常量满足，则存在 $x$ 满足      |

**苏格拉底三段论证明示例**：
- 前提：$(\forall x)(\text{Person}(x) \rightarrow \text{Mortal}(x))$， $\text{Person}(\text{Socrates})$
- 结论：$\text{Mortal}(\text{Socrates})$
- 证明：UI 得 $\text{Person}(\text{Socrates}) \rightarrow \text{Mortal}(\text{Socrates})$，假言推理即得。

## 知识图谱推理
知识图谱是由有向图描述实体及关系的知识表示，三元组 `<头实体, 关系, 尾实体>` 可表示为一阶逻辑，支持推理以发现新知识。

### FOIL 归纳推理

FOIL 通过序贯覆盖学习一阶规则，目标谓词作为规则头，逐步添加前提约束谓词直至不覆盖任何反例。

**算法流程**：

| 步骤 | 操作                                                         |
| :--- | :----------------------------------------------------------- |
| 1    | 将目标谓词作为所学规则的结论。                               |
| 2    | 逐一将其他谓词作为前提加入，计算**FOIL信息增益**，选取增益最大的谓词加入规则，并去掉不满足的样例。 |
| 3    | 重复步骤2，直到规则不覆盖任何反例。                          |

**信息增益公式**：
$$FOIL\_Gain = \widehat{m}_{+} \cdot \left( \log_2\frac{\widehat{m}_{+}}{\widehat{m}_{+} + \widehat{m}_{-}} - \log_2\frac{m_{+}}{m_{+} + m_{-}} \right)$$
其中 $m_{+}, m_{-}$ 为原规则覆盖的正反例数，$\widehat{m}_{+}, \widehat{m}_{-}$ 为加入新前提后的正反例数。

### 路径排序推理 (PRA)

PRA 将实体间的关联路径作为特征，训练关系分类器。

| 阶段           | 说明                                               |
| :------------- | :------------------------------------------------- |
| **特征抽取**   | 随机游走、BFS/DFS 生成连接实体对的路径集合。       |
| **特征计算**   | 计算特征值，如到达概率、路径频次或布尔存在性。     |
| **分类器训练** | 用特征训练二分类器，预测新实体对是否存在目标关系。 |

### 其他知识推理方法

| 方法                 | 核心思想                                                     |
| :------------------- | :----------------------------------------------------------- |
| **基于分布式表示**   | 将实体和关系嵌入低维向量空间，通过向量运算（如 $\mathbf{e}_{\text{head}} + \mathbf{r} \approx \mathbf{e}_{\text{tail}}$）进行推理。 |
| **马尔可夫逻辑网络** | 结合马尔可夫网络与一阶逻辑，在概率框架下处理不确定性和关系推理。 |

## 因果推理
因果关系是现象间“引起和被引起”的关系。因果推理判断原因与结果间的必然联系，是比相关性更强的推断。

### 辛普森悖论

在总体样本上成立的关系，在分组样本中可能完全相反。例如：总体不用药恢复率更高，但按性别分组后用药恢复率均更高。这说明了忽略混杂变量可能导致错误结论，需要因果分析。

### 结构因果模型 (SCM)

- **SCM** 由外生变量集 $U$、内生变量集 $V$ 和一组函数 $F$ 组成，$X$ 是 $Y$ 的直接原因当且仅当 $X$ 出现在给 $Y$ 赋值的函数中。
- **因果图**：有向无环图 (DAG)，结点为变量，边表示直接因果依赖。可用于乘积分解联合概率。

### 因果图的基本结构

| 结构     | 图示                            | 条件独立性                                             |
| :------- | :------------------------------ | :----------------------------------------------------- |
| **链**   | $X \rightarrow Z \rightarrow Y$ | 给定 $Z$ 时，$X$ 与 $Y$ 条件独立                       |
| **分连** | $X \leftarrow Z \rightarrow Y$  | 给定 $Z$ 时，$X$ 与 $Y$ 条件独立                       |
| **汇连** | $X \rightarrow Z \leftarrow Y$  | $X$ 与 $Y$ 无条件独立；给定 $Z$（或 $Z$ 的后代）时相关 |

**D-分离**：若给定集合 $Z$ 阻塞了 $X$ 与 $Y$ 间的所有路径，则 $X$ 与 $Y$ 条件独立。阻塞条件：路径上的链/分连中间结点在 $Z$ 中，或汇连结点及其后代均不在 $Z$ 中。

### 干预的因果效应

引入 **do 算子** $do(X=x)$ 表示强制固定变量 $X$ 的值为 $x$，消除指向 $X$ 的边后计算 $Y$ 的分布。

- **因果效应差**：$P(Y=1|do(X=1)) - P(Y=1|do(X=0))$
- **调整公式**（已知混杂 $Z$ 时）：
  $$P(Y=y|do(X=x)) = \sum_z P(Y=y|X=x, Z=z)P(Z=z)$$
  用无干预下的条件概率即可计算因果效应。

### 反事实模型

反事实回答“如果当时做了不同选择，结果会怎样”的问题。计算步骤：

| 步骤        | 操作                                                         |
| :---------- | :----------------------------------------------------------- |
| **1. 溯因** | 利用证据 $E$ 推断外生变量 $U$ 的值。                         |
| **2. 动作** | 修改模型，将原因变量 $X$ 强制设为反事实值 $x$，得到修正模型 $M_x$。 |
| **3. 预测** | 在 $M_x$ 和已推断的 $U$ 下计算结果变量 $Y$ 的值。            |

### 因果分析的层次化 (Pearl)

| 层次       | 典型问题                    | 表达式                             |
| :--------- | :-------------------------- | :--------------------------------- |
| **关联**   | “看到 $A$ 会怎样？”         | $P(y|A)$                           |
| **干预**   | “如果做 $A$ 会怎样？”       | $P(y|do(A))$                       |
| **反事实** | “如果当初没做 $A$ 会怎样？” | $P(y'|A)$（在已发生 $A$ 的情况下） |

## 小结
逻辑与推理是人工智能的核心支柱。命题逻辑和谓词逻辑为知识表示和自动推理提供了形式化基础；知识图谱推理扩展了从大规模知识中获取新关系的能力；因果推理则超越相关性，揭示变量间的本质因果机制。三者共同构成了智能系统进行演绎、归纳与因果推断的理论框架。
