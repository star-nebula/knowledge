# AI 产业格局

当前 AI 产业围绕**大模型**形成三层生态：基础设施、模型层、应用层。

## 三层结构

| 层级 | 核心玩家 | 商业模式 |
|------|---------|---------|
| 基础设施 | NVIDIA、AWS、Azure、Google Cloud | 卖算力（GPU/TPU）、云服务 |
| 模型层 | OpenAI（GPT）、Anthropic（Claude）、Meta（Llama）、Google（Gemini）、国内大厂 | 闭源 API 收费、开源模型生态 |
| 应用层 | 垂直领域 SaaS、企业自研、AI Agent 创业公司 | 订阅制、按调用量、项目制 |

## 关键趋势

### 1. 闭源 vs 开源

- **闭源**：OpenAI、Anthropic 追求性能领先，API 化服务
- **开源**：Meta（Llama）、Mistral、国内大厂（Qwen、Baichuan）推动生态，催生私有化部署

### 2. 垂直化

通用大模型 → 行业大模型（金融、医疗、法律、教育）→ 企业专属模型。

### 3. 多模态融合

文本、图像、语音、视频统一建模（GPT-4V、Gemini 1.5、Sora）。

### 4. 智能体（Agent）生态

AI 自主规划、使用工具、联网搜索、执行任务，成为应用层新形态。

## 国内格局

| 玩家 | 模型 | 定位 |
|------|------|------|
| 百度 | 文心一言 | 全栈（云+模型+应用） |
| 阿里 | 通义千问 | 云服务 + 开源 |
| 腾讯 | 混元 | 内部业务 + 对外 API |
| 字节 | 云雀 | 内容生成 + 豆包 |
| 创业公司 | 智谱、月之暗面、零一万物 | 专注模型层或应用层 |

## 挑战

- **算力依赖**：GPU 卡脖子风险
- **数据合规**：高质量数据获取与版权
- **成本**：训练/推理开销巨大
- **安全对齐**：幻觉、偏见、滥用
