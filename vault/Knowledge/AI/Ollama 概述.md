# Ollama 概述

Ollama 是一款**简化 LLM 本地部署和运行**的开源工具，支持 Llama、DeepSeek、通义千问等主流模型，覆盖 macOS / Windows / Linux。

官网：[https://ollama.com/](https://ollama.com/)

## 六大特点

| 特点 | 说明 |
|------|------|
| **一站式管理** | 模型权重、配置、数据打包为 `Modelfile`，统一管理 |
| **热加载** | 无需重启即可切换不同模型 |
| **丰富模型库** | 预构建 Llama 2/3、通义千问、DeepSeek 等 |
| **多平台支持** | macOS / Windows / Linux 全平台覆盖 |
| **无复杂依赖** | 优化推理代码，支持纯 CPU 和 Apple Silicon |
| **资源占用少** | 代码简洁，本地高效运行 |
