# 前端开发

## 概述

前端能力是 AI 应用开发者的差异化竞争力——大多数 AI 工程师只懂后端，能独立做出前端交互界面的很少。从 HTML/CSS 基础到 Vue3 现代框架，本专题覆盖从 0 到 1 的前端开发知识链。

## 知识点

### 基础三件套

- [[Archive/2026-07-前端开发迁移备份/前端开发/HTML]]：语义化标签、表单元素、HTML5 新特性
- [[Archive/2026-07-前端开发迁移备份/前端开发/CSS]]：盒模型、Flexbox/Grid 布局、响应式设计、CSS 变量
- [[Archive/2026-07-前端开发迁移备份/前端开发/JavaScript]]：ES6+ 语法、DOM 操作、事件循环、异步编程（Promise/async-await）

### 数据格式与库

- [[JSON]]：前后端数据交换的标准格式
- [[jQuery]]：经典 DOM 操作库，虽不再主流但大量老项目仍在使用

### CSS 框架

- [[Bootstrap]]：快速搭建响应式页面的 UI 框架，栅格系统和组件库

### 现代框架

- [[Vue3基础]]：组合式 API、响应式系统、组件化开发——目前最主流的前端框架之一
- [[前端开发]]：前端工程化概览——构建工具（Vite/Webpack）、包管理（npm/pnpm）、模块化

## 学习路径

```
HTML → CSS → JavaScript → JSON/jQuery → Bootstrap → Vue3 → 前端工程化
```
