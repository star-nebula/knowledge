# 复杂度分析

不依赖实际运行环境，从理论层面评估算法的效率上限。

## 时间复杂度

评估算法运行时间随输入规模 $n$ 增长的趋势，使用大 $O$ 表示法描述上界。

| 复杂度 | 名称 | 典型算法 |
|--------|------|---------|
| $O(1)$ | 常数 | 数组索引访问 |
| $O(\log n)$ | 对数 | 二分查找 |
| $O(n)$ | 线性 | 遍历数组 |
| $O(n \log n)$ | 线性对数 | 快速排序、归并排序 |
| $O(n^2)$ | 平方 | 冒泡排序 |
| $O(2^n)$ | 指数 | 暴力搜索子集 |
| $O(n!)$ | 阶乘 | 全排列 |

**递归复杂度**：$T(n) = a \cdot T(n/b) + f(n)$，通过主定理求解。

## 空间复杂度

评估算法内存占用随输入规模的增长趋势。

- **输入空间**：存储输入数据本身
- **辅助空间**：算法运行额外申请
- **原地算法**：辅助空间 $O(1)$，如冒泡排序
