# 分治算法

将问题**分解**为独立子问题 → 递归求解 → **合并**子问题的解。

## 三阶段

1. **分解**：拆分为相同形式的子问题
2. **解决**：递归求解（足够小时直接解）
3. **合并**：整合子问题的解

## 复杂度分析

递推式 $T(n) = a \cdot T(n/b) + f(n)$，通过**主定理**求解：
- 若 $f(n) = O(n^{\log_b a - \varepsilon})$，则 $T(n) = \Theta(n^{\log_b a})$
- 若 $f(n) = \Theta(n^{\log_b a})$，则 $T(n) = \Theta(n^{\log_b a} \log n)$
- 若 $f(n) = \Omega(n^{\log_b a + \varepsilon})$ 且 $af(n/b) \le cf(n)$，则 $T(n) = \Theta(f(n))$

## 典型应用

归并排序、快速排序、二分查找、汉诺塔。
