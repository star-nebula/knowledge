# 排序算法

## 算法对比

| 算法 | 时间（平均） | 时间（最坏） | 空间 | 稳定 | 原地 | 策略 |
|------|:----------:|:----------:|:----:|:---:|:---:|------|
| 选择排序 | $O(n^2)$ | $O(n^2)$ | $O(1)$ | 否 | 是 | 每轮选最小 |
| 冒泡排序 | $O(n^2)$ | $O(n^2)$ | $O(1)$ | 是 | 是 | 相邻交换冒泡 |
| 插入排序 | $O(n^2)$ | $O(n^2)$ | $O(1)$ | 是 | 是 | 插入已排序区 |
| 快速排序 | $O(n \log n)$ | $O(n^2)$ | $O(\log n)$ | 否 | 是 | 哨兵划分+递归 |
| 归并排序 | $O(n \log n)$ | $O(n \log n)$ | $O(n)$ | 是 | 否 | 递归二分+合并 |
| 堆排序 | $O(n \log n)$ | $O(n \log n)$ | $O(1)$ | 否 | 是 | 建堆+反复出堆 |
| 桶排序 | $O(n+k)$ | $O(n^2)$ | $O(n+k)$ | 是 | 否 | 分桶→排序→合并 |
| 计数排序 | $O(n+k)$ | $O(n+k)$ | $O(k)$ | 是 | 否 | 频率统计+前缀和 |
| 基数排序 | $O(d(n+k))$ | $O(d(n+k))$ | $O(n+k)$ | 是 | 否 | 逐位稳定排序 |

## 选择原则

- **小数据量**：插入排序（简单高效）
- **稳定性要求**：归并排序、冒泡排序
- **原地排序 + 通用**：快速排序（首选）
- **严格 $O(n \log n)$**：归并、堆排序
- **整数且范围小**：计数排序
