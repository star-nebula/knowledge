# 数组与链表

两种最基础的线性存储结构，核心差异在于内存组织方式。

## 数组

元素存储在**连续内存**中，通过 `base + i × size` 计算地址，支持 $O(1)$ 随机访问。

- 插入/删除中间元素需 $O(n)$（后续元素整体移动）
- 内存连续，CPU 缓存友好

## 链表

节点**分散存储**，通过指针串联。支持 $O(1)$ 插入/删除（已知位置），访问需 $O(n)$ 顺序遍历。

## 对比

| 维度 | 数组 | 链表 |
|------|------|------|
| 随机访问 | $O(1)$ | $O(n)$ |
| 插入/删除 | $O(n)$ | $O(1)$ |
| 内存布局 | 连续 | 分散 |
| 缓存友好 | 是 | 否 |
| 额外开销 | 无 | 指针 |
