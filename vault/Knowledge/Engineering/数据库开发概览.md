# 数据库开发概览

> 数据存储层全景：关系型与 NoSQL 数据库的选择与使用。

## 为什么需要数据库

| 存储方式 | 特点 | 场景 |
|----------|------|------|
| 变量（列表/字典） | 临时存储，程序结束即丢失 | 运行时中间数据 |
| 文件 | 永久存储，但不便精细化管理 | 日志、配置 |
| **数据库** | 永久存储 + 结构化 + CRUD 高效 | **生产环境数据** |

> CRUD：Create（增）、Read（查）、Update（改）、Delete（删）

## 数据库分类

### 关系型数据库

- 采用**二维表格**模型组织数据
- 表与表之间有关系（一对一、一对多、多对多）
- 支持 SQL 查询语言，事务保证数据一致性
- 代表：**[[Python MySQL|MySQL]]**、Oracle、PostgreSQL、SQLite

### 非关系型数据库（NoSQL）

- Key-Value 方式存储数据，类似 Python 字典
- 读写速度极快，适合缓存和高并发场景
- 代表：**[[Python Redis|Redis]]**、MongoDB（文档型）、HBase

## Python 操作数据库

| 数据库                       | Python 驱动  | 说明             |
| ------------------------- | ---------- | -------------- |
| [[Python MySQL \| MySQL]] | `pymysql`  | 连接、执行 SQL、事务处理 |
| [[Python Redis \| Redis]] | `redis-py` | 数据类型操作、发布订阅、管道 |

## 学习路径

```
SQL 基础 → MySQL 进阶（索引/事务/锁）→ Redis 缓存 → Python 操作数据库
```
