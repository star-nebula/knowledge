入门：基础语法 → 数据结构 → 函数入门 → 类入门

实战：异常处理 → 文件操作 → 模块与包 → 标准库
深入：多进程与多线程 → 协程与异步 → 迭代器进阶 → 反射 → 元类 → 垃圾回收
部署：PyInstaller 打包 → Django 项目实战 → 注册表模式
