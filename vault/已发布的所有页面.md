# 站点笔记总索引

> 本页汇总站点中的全部笔记，按所属分类列出，便于一览与跳转。
> 数据由 Dataview 自动汇总，新增或移动笔记后无需手动维护本页。

## 全部笔记（Dataview 自动汇总）

```dataview
TABLE file.folder AS 分类
FROM "笔记" OR "作坊" OR "档案"
WHERE file.name != "index"
SORT file.folder ASC, file.name ASC
```
