# 已发布内容索引

> 本文件夹是「发布台账」，收录我发布到网络平台的所有内容（不区分平台，只要是发布出去的都归这里）。
> - **vault 中已有原稿的**：用 `![[原稿]]` 嵌入引用，不复制正文（单一信息源）。
> - **vault 中没有的**：把发布正文落盘归档于此（线上内容的本地副本）。
> - 新建发布笔记请用模板 `PublishedNote`。

## 全部已发布内容（Dataview 自动汇总）

```dataview
TABLE date_published AS 发布日期, link(url, "查看") AS 链接
FROM -"Templates"
WHERE status = "published"
SORT date_published DESC
```
