Docker 核心概念 ​

Docker 是一个容器化平台，将应用及其依赖打包进轻量级容器，实现"一次构建，到处运行"。

三大核心组件 ​

组件说明类比
镜像（Image）只读模板，包含应用运行所需的一切类（Class）
容器（Container）镜像的运行实例，相互隔离对象（Object）
仓库（Registry）存储和分发镜像的中心化服务GitHub

基本工作流 ​

shell
docker pull nginx       # 从仓库拉取镜像
docker run -d nginx     # 以后台模式启动容器
docker ps               # 查看运行中的容器
docker stop <id>        # 停止容器
docker rmi nginx        # 删除镜像

镜像拉取受限时，可借助第三方脚本绕过网络限制。
