BaiduSync 盘长路径删除需扩展前缀 ​

现象：shutil.rmtree 删除含深层开源仓库（如 dify-main 的 weaviate 卷目录）的文件夹时报 FileNotFoundError，反复重试无效，目录残留数千文件。

原因：路径总长超 Windows 260 字符上限（实测最长 266），普通 Win32 API 删除失败；rmtree 的报错被包装成 FileNotFoundError 误导排查。

解法：用 \?\ 扩展长度前缀自底向上删除——先 os.walk(prefix+root, topdown=False) 逐文件 os.remove，再逐目录 os.rmdir。复制同理：robocopy 原生支持长路径，比 Python copytree 可靠。

适用：任何含 node_modules / .git / 深层开源仓库的目录操作。
