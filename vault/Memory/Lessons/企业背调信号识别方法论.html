企业背调信号识别方法论 ​

提炼自 qiye-beidiao 工作区 .workbuddy/memory/MEMORY.md（23 条已验证 + 1 条候选），每个方法后括注验证案例。与 企业入职背调八阶段流程 配套使用；单案详情见 Memory/Projects/qiye-beidiao/working/journal。

主体核验类 ​

  1. 同名主体必须排除：建材/家居行业「汉狮」「华狮」类字号高频重复，逐一核对统一社会信用代码与股东链，确认无关联后明确写进报告（汉狮案：中山汉狮光电/广州汉狮光电均与目标无关）。
  2. 招聘平台公司名 ≠ 主体错配：先查统一社会信用代码 + 曾用名链；企业更名后平台常不同步（汉狮：佛山汉狮建材科技→汉狮光动科技(佛山)→(广东)）。
  3. 楼宇新旧名对照法（候选，优家门业案，未定稿）：JD 地址与工商地址字面不同时，先查大楼业主/主租户的工商注册地址比对楼名别称（瑞恒科创园=瑞洲科技大厦）。

规模与经营信号类 ​

  1. 招聘平台「公司规模」字段是 HR 自填，不可信：可能与工商年报参保人数差一个数量级（专氪：平台"10-50人" vs 参保 1 人；领创"50-99人" vs 参保 0）。一律以工商年报参保人数为准。
  2. 参保人数趋势是高价值信号：连续两年下滑（194→162→155）比单年数据更能说明问题（汉狮案）。
  3. 财务数据缺失时不自动判负：写明"无法验证"并降置信度，用实缴注册资本、纳税信用等级、参保人数趋势、资质荣誉做侧面印证。
  4. 「在招时长」信号需打折：先看该公司其他岗位更新时间分布；若多数岗位长期未动，说明"挂上不维护"，不能推断为招不到人或虚假引流（汉狮案：销售/结构工程师岗停在 2023-03）。
  5. 「在招时长」查不到时不要硬猜：搜索引擎对 BOSS直聘/智联岗位详情页索引极弱。正确做法=可核验时间锚点 + 标注推断置信度 + 用户 3 步自测法（平台"X天前更新"截图 / 同公司其他岗位时间分布 / 直接问 HR）。
  6. 「小公司招高岗」≠ 虚假岗位：先查当地产业带政策背景。顺德龙江 2000+ 家具企业、2025 规上产值 682 亿、镇政府将"深耕 AI 智造"列三大赛道之首并联合华为/中软国际建实验室 → 家具厂招 AI 岗是产业带普遍现象（专氪案，已交叉验证鸿中家具同招 AI 人才）。

JD 分析类 ​

  1. JD「穿越条目」是识别模板 JD 的高效抓手：与业务明显无关的优先项（办公椅厂 JD 写"工具类/教育类 APP 经验优先"）、或要求配合公司根本不存在的岗位（1 人参保却要"配合测试工程师"）→ 公司没想清楚要招什么人，岗位风险显著上调（专氪案）。
  2. JD 全软素质 + 热词岗位名 = 模板引流岗：岗位名挂热词（AI运维）但任职要求全"善于沟通/学习能力"、无硬技能门槛无薪资无地点 → 注水/引流概率显著上调，可与 #10 并用（领创案）。
  3. JD 内部自洽性检查：工时/福利极详尽却独缺薪资区间 → 高权重警示；JD 自相矛盾（"不需要前后端开发"但职责含脚本开发/接口对接）→ 职责漂移风险高（艾梦尔案，与 #10 同源）。
  4. 「AI生成师」类引流岗画像：热词岗位名 + 接受无基础 + 无责底薪 + "项目奖励"无计提规则 + JD 零工具名零作品要求 + 0 参保公司里 JD 要协助的岗位不存在。与 BOSS直聘高发违规「以招聘为名招生收费」画像重合 → 面试第一优先核实"是否存在培训/考证/押金/分期"（启慈案）。
  5. 招聘岗位班底反推业务实体：垂直招聘网（康强网等）的岗位清单（医师/药师/店长/理疗师）能反推公司真实业务形态（养生门店），比"大而全"经营范围更真实。适用：经营范围横跨多行业、公司自述全是概念词（晟瑞景安案）。
  6. 垂直招聘网自报成立年份可能与工商不符（晟瑞景安案：康强网挂 2021，工商实为 2026-03）→ 作为"包装痕迹"信号写进报告并列入面试核实项。

关联主体穿透类 ​

  1. 电话比对法：比对关联公司工商登记电话与招聘启事联系人手机号，可低成本建立"是否同一批人"的强证据（专氪招聘联系人 == 佰群网络工商登记电话）。
  2. 注册地址「同楼层邻居检视法」：查注册地址所在楼层其他注册企业（mingluji 写字楼名录等）；同层/同号段出现代办注册、代理记账公司且一址多照普遍 → 标记"集群注册/挂靠地址嫌疑"，提示面试实地验证（晟瑞景安案：智富大厦3205层）。
  3. 楼宇注销率 = 集群注册的量化指标：用楼宇入驻企业分析工具，注销吊销占比 >40%（启慈案：龙光尚街 1343 家注册、45.8% 注销）即可直接标记"集群注册"高嫌疑，比逐层查邻居更快。
  4. 「同地址房间号检视法」：同一地址不同房间号注册多家关联公司 + 共用招聘电话 + A 公司招聘岗写 B 公司工作地点 → 家族多壳集群（艾梦尔案：和政路12号4楼 402-408 五家，简鸭家居为控股平台）。此类架构劳动合同主体易被腾挪，"合同主体是谁"列面谈第一优先；新壳改名接老店（暖眠阁→艾梦尔智能家居接 1688"7年店龄"老店）是常见包装手法。
  5. 「法人轮换双壳」识别法（启慈案）：同一批自然人名下多家壳，经营范围逐字近似、注册资本同为 100 万未实缴、参保同为 0，法人/股权在壳间近期轮转 → 多壳轮换经营/招聘，合同主体腾挪风险极高。核查抓手：变更记录里"变更前后投资人/法人名单"的姓名交叉。
  6. 「乔迁表彰工龄锚定法」（广豫案）：公司乔迁/年会通稿表彰"入职 N 年"员工，与关联壳成立年份交叉——工龄早于当前招聘主体成立时间即证明"壳新团队老"；跨壳关键人物（监事/主管同名者）可串联整个壳链。
  7. 启信宝「集团/族群」页穿透法（广豫案）：搜"XX集团 启信宝"或从成员企业页点入集团页，一次拿到成员清单、注册资本总和、参保总和、疑似空壳数、集团风险计数——比逐企查股权关联快一个量级，多壳案优先用此入口。

结构性质辨类 ​

  1. 大集团「集团壳挂名招聘」≠ 壳公司诈骗：集团控股壳（参保 0 人）统发招聘、旗下实体用工、地址一致，属常规操作（鹰牌案：广东鹰牌集团参保 0 人挂名，实际用工主体佛山石湾鹰牌 475 人参保）。风险点是"劳动合同/社保由谁缴"而非公司真实性；抓手=查集团壳与旗下实体参保人数差 + 招聘地址归属。与多壳轮换的区别：集团壳有真实集团+实体参保支撑；无集团背景的 0 参保壳+法人轮换=高危。
  2. 区分「被执行」与「失信」：被执行 + 已出具结案通知书 ≠ 老赖；但「劳动合同纠纷」类执行案对求职者是高权重信号（汉狮案）。
