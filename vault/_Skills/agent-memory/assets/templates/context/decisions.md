## 分类标签含义

| 标签 | 含义 | 何时使用 |
|------|------|---------|
| `[架构]` | 系统架构、模块划分、数据流 | 改模块边界、选架构模式、定数据流向 |
| `[工具]` | 依赖/库/第三方服务选型 | 选 ORM、换 HTTP 库、接云服务 |
| `[约定]` | 代码规范、命名、流程 | 统一 API 格式、定分支策略、约定错误处理 |
| `[性能]` | 性能优化策略 | 加缓存、改索引、优化算法选型 |
| `[安全]` | 安全策略与措施 | 认证方案、加密选型、权限模型 |
