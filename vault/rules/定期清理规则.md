# 定期清理规则

## 1. 清理周期

- **月度轻检**：每月检查一次正文中标注 `⚠️ 未验证` 的笔记
- **季度复审**：每季度全面复审一次，处理过期和废弃内容

## 2. 清理对象与操作

| 状态 | 判断标准 | 操作 |
|------|---------|------|
| `⚠️ 未验证` | 创建超过 30 天仍未完善 | 扩展为正式笔记，或降级为极简速记，或删除 |
| `⚠️ 未验证`（长期） | 标注超过 60 天仍未确认 | 查阅资料验证后改为 `已验证`，或标记 `已过时` |
| `已过时` | 内容已被新版本替代或不再准确 | 更新为最新内容，或在 tags 中标注 `#已废弃` |
| 重复笔记 | 同一主题存在多篇内容重叠的笔记 | 保留最新/最完整版，其余在 tags 中标注 `#已废弃` |

## 3. 清理注意事项

- 删除笔记前，先搜索是否有其他笔记链接到它，如有则更新链接
- 废弃笔记在 tags 中添加 `#已废弃` 标记
- 日期后缀的历史版本（如 `XX-202601.md`）：如果最新版已涵盖其内容，直接删除历史版本
