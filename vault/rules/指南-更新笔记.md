# 场景指南：更新笔记内容

> 更新已有笔记时，按以下步骤执行。

---

## 操作步骤

### 1. 读取现有笔记

先读取笔记内容，了解：
- 当前 frontmatter 结构
- 当前内容结构
- 是否有链接需要检查

### 2. 更新 Frontmatter

**必须更新 `created` 字段**为当前日期：
```yaml
created: 2026-06-27  # 修改为今天的日期
```

其他字段如有变化也需更新：
- `difficulty`：掌握加深后调整
- `tags`：新增或调整标签
- `source`：补充新的来源

### 3. 更新内容

根据更新类型执行：

| 更新类型 | 操作 |
|---------|------|
| 补充内容 | 在合适位置添加新内容 |
| 修正错误 | 直接修改错误内容 |
| 重构结构 | 调整章节结构，保持逻辑清晰 |
| 添加示例 | 在相关概念后添加代码示例 |

### 4. 检查链接

更新内容时，检查：
- 新增内容中的链接是否有效
- 是否需要添加新的链接
- 已有链接是否仍然有效

### 5. 检查粒度

更新后检查笔记粒度：
- 如果内容超过对应类型的字数上限，考虑是否需要拆分（字数上限见 `原子笔记编写规范` 5.3）
- 如果内容太少，考虑是否需要合并到其他笔记

---

## 检查清单

- [ ] `created` 字段已更新为当前日期
- [ ] 其他 frontmatter 字段已同步更新（如需要）
- [ ] 新增内部链接使用 wikilink 格式
- [ ] 新增外部链接标注访问日期
- [ ] 笔记粒度合理（不超过对应类型字数上限）
