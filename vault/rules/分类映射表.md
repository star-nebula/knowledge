# 知识树分类与物理路径映射表

## 三大领域映射

| 领域 | 对应目录 | 覆盖范围 |
|:-----|:---------|:---------|
| **AI 与模型** | `Knowledge/AI/` | RAG、Agent、NLP、ML、DL、Prompt 工程、模型微调、模型部署、评估与运维 |
| **工程与技术** | `Knowledge/Engineering/` | Python、前端、数据库、Git、Linux、Docker、系统设计、API 设计 |

## 特殊归属

| 内容类型 | 存放路径 | 说明 |
|:---------|:---------|:-----|
| 简历/面试题/项目包装 | `Interview/` | 求职相关集中 |
| 闪念/灵感/临时记录 | `Inbox/` | 每周清空 |
| 原始课程资料/论文/剪藏 | `Resources/[来源名]/` | 按来源分，未加工 |
| 笔记模板 | `Templates/` | 7种原子笔记 + MOC + 日记模板 |
| 操作规范与指南 | `rules/` | 场景指南、编写规范、清理规则 |
| 不再活跃的旧内容 | `Archive/` | 归档 |

## 跨领域判断规则

当内容可能属于多个领域时，按**主要视角**判断：

| 判断规则 | 示例 |
|:---------|:-----|
| 以"模型怎么用"为主 → AI | "用 Ollama 部署 Llama3" → `Knowledge/AI/` |
| 以"部署系统怎么搭"为主 → Engineering | "Docker Compose 部署流水线设计" → `Knowledge/Engineering/` |
| 以"怎么学"为主 → Methods | "如何高效阅读论文" → `Knowledge/Methods/` |
